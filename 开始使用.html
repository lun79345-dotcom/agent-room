AGENT ROOM · MAC 内测版 0.2

你的 AI 工作小组，
从这里开始。

你确定方向，Claude 主管拆解和跟进，两位 Codex 员工完成各自的工作。讨论在群聊里，工作也能回到原应用继续。

01 · 准备本机环境

安装运行环境和两个应用

本内测版面向 Mac。需要 Node.js 22 或更高版本、Claude Code 与 Codex CLI。要回到原应用工作，还需要 Claude Desktop 和 Codex 桌面入口。

CLI 是群聊连接本机应用的程序。只安装桌面应用不一定已经具备所需 CLI；请按各自官方说明完成安装。

02 · 使用自己的账号

分别完成 Claude Code 和 Codex CLI 登录

使用你自己的可用账号和额度，按官方程序提示登录。Claude 原应用入口需要可用订阅。浏览器或桌面应用已登录，不代表 CLI 已登录。

一个人的多位 AI 员工共用对应账号的额度，每位员工保留独立会话。此内测包不包含开发者的账号、聊天记录或会话。

03 · 打开群聊

解压后，双击“启动员工群.command”

把整个文件夹放在长期保留的位置，然后双击启动文件。浏览器会打开本机员工群，页面会检查程序、登录、版本接口和员工工作目录。

有缺失项目时，点击“使用前检查”查看解决方法。若已安装程序但没找到，可以在检查窗口里填写程序位置。

这是文件夹形式的内测包，尚未提供签名安装程序。如果 macOS 提示无法打开，请按系统提供的正常打开与授权流程操作。

04 · 第一次使用

先确认分工，再交办具体工作

  1. 点击“先确认分工”，建立各员工自己的会话。
  2. 在员工设置里填入要工作的项目文件夹。
  3. 选择“交办工作”，发给 Claude 主管，写清要求与验收标准。
  4. 两位 Codex 员工返回结果后，主管会汇总一次。

“群聊讨论”只交流计划和进度。在这个模式里说“开始”，不会自动执行文件修改。讨论定好后，切换“交办工作”提交完整要求。

05 · 回到原应用与处理故障

保留同一个员工、同一个会话

员工卡片可以打开原应用。Codex 留在原应用时仍可接收群消息，消息会排队处理。Claude 在原应用工作时，结束后点击“回群聊”继续管理。

  • 没有回复：查看员工卡片的原因，检查账号、网络和原会话；等待中的队列可能需要先在原应用继续。
  • 失败讨论：按页面提示处理后，可以点“再联系一次”。
  • 未完成任务：在任务详情点击“继续这项任务”，员工会先核对已有成果。
  • 需要重启：先结束当前群聊工作，再双击“重新启动群聊.command”。停止后台服务使用“停止员工群.command”。

重启不会自动重做已中断任务。两位员工同时修改同一项目时，要安排不同文件；此版本没有自动隔离工作目录。

本工具在自己的电脑上运行，模型调用仍连接各自服务并使用对应额度。它尚未实现多人远程共享群聊、Claude 原应用持续双向管理和无人值守恢复。详细说明见同目录 README.md 和内测说明.md。
